# 常驻任务显示

任务显示独立于只读[任务浏览器](task-viewer.md)，无需当前会话绑定任务。

## 显示与配置

默认在输入框上方显示 `▸ trellis(N)`；绑定任务时追加任务名、状态和规划文档状态。数量包括项目任务目录中尚未完成的父子任务，排除 completed、归档及重复别名。

- 正数使用强调色，零为淡色；读取失败或数据不完整显示 `(?)`，不把部分计数当作零。
- `TRELLIS_PI_STATUS=status` 改用底栏，`off` 关闭；不支持的项目不显示。显示模式不改变上下文注入。
- 底栏空间有限，长任务名会截短；它与其他扩展共用一行，终端较窄时仍可能被宿主裁剪。默认 widget 是独立行。
- 新会话、回合结束及任务 CLI 返回时刷新；没有持续轮询或文件监听，手动外部修改不保证立即显示。

完整环境变量配置见 [README](../README.md#where-the-task-display-goes)。
