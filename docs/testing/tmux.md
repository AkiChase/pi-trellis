# 用 tmux 验证真实终端交互

本指南改编自相邻 my-pi-preset 的 `docs/testing/tmux.md`，用于 pi-trellis 的真实 CLI/TUI 冒烟，不是某次测试的通过记录。自动组件测试、真实终端交互和在线模型质量是不同证据层；一次离线终端测试不能覆盖任意主题、IME、插件组合或 provider。

## 1. 隔离与授权

运行前说明动作、测试矩阵和清理范围，取得真实终端测试授权。只使用已安装的 CLI 和 tmux，不临时下载依赖，不连接用户现有 pane。文档整理本身不授权运行测试。

- 使用唯一 `tmux -L <test-id>` 服务；所有管理命令都带同一 `-L`，禁止无参数 `kill-server`。
- 自建临时 HOME、`PI_CODING_AGENT_DIR`、cwd、session、配置、日志目录，不能继承个人认证或包注册。
- 优先用 `env -i` 显式提供必要 PATH、TERM 和隔离变量。禁用自动资源发现，显式 `-e` 加载当前检出的目标扩展；具体参数先核现有 CLI 帮助。
- 使用脚本化本地 provider 或最小无模型流程，不访问线上接口。需要 provider 的用例要报告它是夹具，不是自主执行质量。
- 不 install、全量 sync 或 reload 个人实例。测试依赖缺失时标记不可执行，不安装第二套 SDK。
- 按功能选择一次性项目夹具：任务浏览器无需已部署 runtime，可直接准备隔离任务文件；初始化写入只发生在自建临时项目，并通过原生确认；派发测试需要完整兼容 runtime、角色和持久 adapter 配置。父进程一次性 `-e` 不证明子代理能加载 adapter，见[派发说明](../dispatch.md)和[初始化说明](../initialization.md)。不借测试绕过 manifest 或 worktree 校验。

## 2. 先跑最小矩阵

先验证一条成功、一个错误、展开/收起或进入/返回的核心键位，再扩展专项。不要一开始搭完整 agent/workflow 测试系统。

按变更选择矩阵并记录未跑项目：

| 维度 | 示例 |
| --- | --- |
| 模式 | regular、fullscreen |
| 宽度 | 140、80、40 列；动态 resize 另测 |
| 主题 | 明确固定 dark/light/system 之一，不能互相代称 |
| 文本 | 中文、组合字符、长路径/标题、控制字符、空态/错误态 |
| 输入 | 真实键位、Esc 取消、返回、焦点恢复、必要的 dialog |
| 生命周期 | 新会话、关闭、正常 quit 及实际进程清理 |

固定宽度启动不是动态 resize。键盘矩阵通过不代表物理鼠标或 IME 通过。任务浏览器可从进入列表、Enter 打开、左右切换、Esc 返回、`r` 刷新和焦点恢复开始；初始化可从取消无写入与一次自有项目成功流程开始，不把菜单模拟当真实画面。

## 3. 驱动、等待与采集

使用 `tmux send-keys` 发送实际键位，例如 `C-o`，保存动作前后证据确认它确实发生。不要只相信 driver 发键成功；按目标功能实际注册的键位选择动作。

用有界条件循环或 monitor 等待期望画面、事件或原始帧；不能用固定 sleep 猜完成时间。设置总体截止和明确失败出口，防止等待无限挂起。

- `capture-pane -p` 保存文本，`capture-pane -p -e` 保留 SGR；这是屏幕文本，不是图片截图。
- 需要排查渲染时，用 `PI_TUI_WRITE_LOG` 采集自有原始 ANSI 写流（先确认已有 CLI 支持）。保存有限片段和动作标记，检查没有凭证。
- resize 后必须在原始 CLI 输出中确认新宽度完整帧已结束，再判断画面。tmux 可能裁剪旧帧；单凭 border 长度会误判。
- 背景一致性按显示 cell 核查。存在 48m 不代表整行连续，标题省略后的 0m/49m 可能提前取消背景。
- 通过 stdin 发送鼠标 SGR 字节只能称输入模拟，不能称物理鼠标端到端验证。
- `/debug` 或事件日志不能替代实际 overlay 画面和焦点证据。

## 4. 报告与夹具误判

每项单独标记 PASS、FAIL、NOT_RUN，报告命令、CLI 版本、主题、模式、尺寸和退出码。driver 捕获异常后 exit 0 不代表成功；同时审阅 report.error、各 case、screens 和 events。

产品失败和夹具失败分开保留。标签变化、选项排序或旧帧裁剪可能是夹具问题，但必须核实际源码和原始帧后才下结论；不改产品或预期来迁就失败。修夹具后重新跑受影响矩阵，保留首次失败记录。

在线模型、第三方原包兼容、物理 IME、任意插件组合没测就标 NOT_RUN。阶段完成不能替代验收。[离线 provider 探针](provider.md)验证宿主机制，不等于真实终端或模型质量。

## 5. 清理

finally 中先向自有 CLI 发送正常 quit，核 CLI 及自有 child 实际退出。必要时只 TERM/KILL 测试 PID 或其进程组；不依据过期 PID 随意发信号。停止唯一测试服务，清除仅自己创建的临时配置。

报告残留进程、超时或清理失败，不把面板关闭/terminal 状态当作 OS 退出。保留有界证据到对应任务 research，操作指南不累计历史 PASS 数量。

## 复用说明

复用任何历史夹具前先读其失败说明、启动参数和版本，不盲跑全量脚本。邻仓专属验收记录不作为本仓库通过证据；本次只引入操作规范，没有运行真实 tmux。通用工程要求见[质量规范](../../.trellis/spec/extension/quality-guidelines.md)。
