# 只读任务浏览器

## 打开与职责

在 Pi 交互终端执行 `/trellis-task-viewer`，不带参数。旧 `/trellis-task` 不再注册。

无需当前任务、已部署运行时或模型请求。浏览器不编辑文件、不切换任务、不运行生命周期命令，也不改变常驻任务数量显示。非项目或不支持终端浏览的模式会给出英文通知。

## 列表与层级

列表显示未归档任务，包括已完成但尚未归档的记录。目录名倒序排列，子任务跟随父任务；当前会话任务所在的整棵顶层树优先显示，祖先和同级顺序不变。这不是精确创建时间排序，`MM-DD` 前缀不能区分年份。

每行显示目录标识和原始标题，相同内容不重复；当前任务带标记。Overview 展示 Name、Title、Path 等元数据。损坏或循环层级会提示，不导致有效任务重复显示。

归档父子引用可以被识别，但归档对象不进入列表：归档子任务隐藏，可见任务的归档父任务不会挡住它。不同归档对象重名会提示歧义，精确路径可消歧义；浏览器不提供归档内容搜索或完整归档列表。

## 键位

| 动作 | 键位 |
| --- | --- |
| 列表选择 / 详情滚动 | Up/Down、PageUp/PageDown |
| 打开详情 | Enter |
| 切换 Overview / PRD / Design / Implement | Left/Right |
| 返回列表 / 关闭 | Esc |
| 重新读取 | r |

返回列表保留位置；刷新尽量保留仍存在的任务选择。各详情页独立保留滚动位置。界面标签为英文，任务和文档使用原文。

## 文档与错误

文档沿用 Pi 当前 Markdown 主题，支持标题、表格、列表、代码等。图片保留可读源文本，不下载图片；HTML 和图表不执行。渲染失败会显示警告，并保留完整可滚动的原文。

只读取项目任务存储内的有效文件，支持项目明确配置的顶层外部任务存储。任务记录限 1 MiB，文档限 2 MiB；超限或非 UTF-8 文件报错，不把截断内容当作成功。

缺失、空文档、已删除任务和不可读文档有不同提示。无效当前任务指针不会阻止浏览；目录读取不完整会给 warning，不冒充空项目。长标题和文档可在详情内滚动查看。
