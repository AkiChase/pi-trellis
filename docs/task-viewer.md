# 只读任务浏览器

## 打开与职责

在 Pi 交互终端执行 `/trellis-task-viewer`，不带参数。旧 `/trellis-task` 不再注册。

已初始化且运行时有效时注册这个 slash 指令；未初始化、旧版不兼容或运行时无效时不注册，只保留 `/trellis-init`。它不是模型 tool；`trellis_dispatch` 才是派发工具。

打开浏览器无需当前任务或模型请求，也不执行 Python；有效运行时是项目激活前提。浏览器不编辑文件、不切换任务、不运行生命周期命令，也不改变常驻任务数量显示。运行中项目失效会拒绝打开并清理旧显示，`/reload` 后撤回指令。不支持终端浏览的模式给出英文通知。

## 列表与层级

列表显示未归档任务，包括已完成但尚未归档的记录。目录名倒序排列，子任务跟随父任务；当前会话任务所在的整棵顶层树优先显示，祖先和同级顺序不变。这不是精确创建时间排序，`MM-DD` 前缀不能区分年份。

每行按当前标记、状态、目录标识和原始标题分列对齐，相同目录名和标题不重复。列宽根据完整列表计算，滚动和选择不会导致列位置跳动；刷新或窗口缩放后重新分配宽度。

超长目录名和标题分别以 `…` 省略，不互相挤占。窄窗口优先显示状态和目录标识，空间不足时隐藏标题；极窄窗口进一步截断，完整内容可进入详情查看。Overview 展示 Name、Title、Path 等元数据。损坏或循环层级会提示，不导致有效任务重复显示。

归档父子引用可以被识别，但归档对象不进入列表：归档子任务隐藏，可见任务的归档父任务不会挡住它。不同归档对象重名会提示歧义，精确路径可消歧义；浏览器不提供归档内容搜索或完整归档列表。

## 键位

| 动作 | 键位 |
| --- | --- |
| 列表选择 / 详情滚动 | Up/Down |
| 打开详情 | Enter |
| 切换 Overview / PRD / Design / Implement | Left/Right |
| 返回列表 / 关闭 | Esc |
| 重新读取 | r |

返回列表保留位置；刷新尽量保留仍存在的任务选择。各详情页独立保留滚动位置。方向键选择任务时才将选中行移入视口；滚轮不会改变选择，Enter 仍打开所选任务。界面标签为英文，任务和文档使用原文。

## 滚动与运行模式

列表和详情正文使用 Pi 原生 ScrollView，右侧常驻滚动条；标题、页签和底栏固定。Fullscreen 模式可在正文上使用鼠标滚轮，到达上下边界不会穿透到主对话。固定标题和底栏上的滚轮不滚动正文，也不影响主对话。不提供任务行点击选择或自定义滚动条点击、拖动。

Regular 模式保留相同的有界正文与滚动条，使用方向键浏览；鼠标仍由终端处理，浏览器不启用额外鼠标捕获，也不切换 Pi 运行模式。关闭后恢复原编辑器焦点和输入。PageUp/PageDown 不作为浏览器快捷键。

为在两种模式的全窗口弹层中使用原生布局，浏览器接入了宿主内部布局接口（已验证 Pi 1.2.0）。Pi 升级可能改变该接口；能力不兼容时会明确通知并拒绝打开或关闭浏览器，不回退到自制滚动条。

## 文档与错误

文档沿用 Pi 当前 Markdown 主题，支持标题、表格、列表、代码等。图片保留可读源文本，不下载图片；HTML 和图表不执行。渲染失败会显示警告，并保留完整可滚动的原文。

只读取项目任务存储内的有效文件，支持项目明确配置的顶层外部任务存储。任务记录限 1 MiB，文档限 2 MiB；超限或非 UTF-8 文件报错，不把截断内容当作成功。

缺失、空文档、已删除任务和不可读文档有不同提示。无效当前任务指针不会阻止浏览；目录读取不完整会给 warning，不冒充空项目。长标题和文档可在详情内滚动查看。
